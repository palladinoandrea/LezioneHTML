<input type="hidden"> - Token CSRF


📤 Dati inviati al server (con token nascosto):
username=Mario&password=*****&csrf_token=a1b2c3d4e5f67890abcdef1234567890

🔐 CSRF Token: Il token nascosto protegge da attacchi CSRF
(Cross-Site Request Forgery) ed è generato dal server.



<input type="hidden"> - Paginazione

📤 Dati inviati al server (con campi hidden):
categoria=elettronica&pagina=2&ordine=prezzo_asc

📄 Paginazione: I campi hidden mantengono lo stato della paginazione
(pagina corrente) e l'ordinamento senza mostrarlo all'utente.
